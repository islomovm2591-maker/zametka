# Zametkalarim

Oddiy zametka ilovasi. Bitta `index.html` fayldan iborat.

- Har bir zametka kun, oy, soat va daqiqasi bilan saqlanadi
- Zametkalarni tahrirlash va o'chirish mumkin
- Qidiruv
- Ikki til: o'zbekcha va ruscha (UZ / RU tugmasi)
- Eslatma: belgilangan vaqtda ovoz, banner va brauzer bildirishnomasi (sahifa ochiq turganda)

Zametkalar brauzerning `localStorage` xotirasida saqlanadi.

## Ishga tushirish

`index.html` faylini brauzerda oching yoki GitHub Pages orqali joylang:
Settings → Pages → Branch: `main`, papka: `/ (root)`.

# Мои заметки (RU)

Простое приложение для заметок в одном файле `index.html`: дата и время у каждой заметки, редактирование, поиск, напоминания, переключатель языка UZ / RU. Заметки хранятся в `localStorage` браузера.
